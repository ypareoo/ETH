# Présentation :

Le projet a été réalisés dans le cadre de la formation en deuxième année d'école d'ingénieur à l'ENSEIRB.

il comsiste en la mise en oeuvre d'une liaison ethernet entre un ordinateur et une carte FPGA.
Un troisième dossier contient du code C++ executant des tâches streamPU pour l'envoi et la réception de trames ethernet.

Pour la prise en main des descriptions verilog ainsi que l'interface Qt, le fichier PDF doc_ETH fourni des informations à ce sujet de même que pour la simple exécution du projet.
